순서대로 준비하기

각 링크는 새 창에서 열립니다. 작업을 마친 뒤 이 페이지로 돌아오세요.

  1. 필수

    Chrome 브라우저 설치

    Brisk Teaching 확장 프로그램을 사용하려면 Chrome이 필요합니다. 이미 설치되어 있다면 다음 단계로 이동하세요.

    설치 후 Chrome을 한 번 실행해 정상적으로 열리는지 확인해 주세요.
    Chrome 다운로드 ↗
  2. 권장

    Chrome을 기본 브라우저로 설정

    연수 중 누르는 실습 링크가 Chrome에서 바로 열리도록 기본 브라우저 설정을 확인합니다.

    짧은 안내 영상을 보면서 내 컴퓨터의 설정을 변경해 주세요.
    설정 영상 보기 ▶
  3. 필수

    Chrome에 Google 계정 로그인

    연수에서 Google Docs를 사용할 계정으로 로그인합니다. 여러 계정을 쓰는 경우 연수용 프로필을 추가하면 편리합니다.

    연수 당일 실제로 사용할 Google 계정인지 확인해 주세요.
    프로필 추가 영상 보기 ▶
  4. 필수

    Brisk Teaching 확장 프로그램 설치

    Chrome 웹 스토어에서 Brisk Teaching을 추가합니다. 설치 후 오른쪽 위 확장 프로그램 메뉴에서 Brisk를 고정해 주세요.

    ‘Chrome에 추가’가 아닌 ‘Chrome에서 삭제’가 보이면 이미 설치된 상태입니다.
    확장 프로그램 설치 ↗
  5. 마지막 단계

    교사용 계정 가입 및 작동 확인

    교사용 가입 페이지에서 계정을 준비하세요. 처음이라면 안내 영상을 따라 가입과 설치를 마친 뒤, Google Docs나 웹페이지에서 Brisk 아이콘이 보이는지 확인합니다.

    Chrome 오른쪽 위 퍼즐 모양 아이콘 → Brisk Teaching 옆 고정 아이콘을 누르면 찾기 쉽습니다.
