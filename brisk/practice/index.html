학생이 글을 쓰기 전에 자신의 생각과 근거를 선택하고 판단하도록 돕는 빈 활동지를 만듭니다.

활동지 생성 프롬프트
초등학교 6학년 국어 주장하는 글쓰기 수업에서 사용할 활동지를 만들어 줘.

활동지의 목적은 학생이 글을 쓰기 전에 자신의 주장, 이유, 근거, 출처, 예상 독자, 설득 전략을 정리하는 것이다.

활동지는 학생이 빈칸을 채우며 생각을 정리할 수 있는 형태로 만들어 줘. 학생이 AI가 준 문장을 그대로 옮기는 방식이 아니라, 자신의 생각을 선택하고 근거를 판단하도록 구성해 줘.

반드시 포함할 항목은 다음과 같아.
1. 내가 주장하고 싶은 내용
2. 그렇게 생각한 이유
3. 주장을 뒷받침하는 근거
4. 근거의 출처
5. 이 근거가 믿을 만한 이유
6. 예상 독자
7. 독자를 설득하기 위해 조심해야 할 표현
8. 초안을 쓸 때 스스로 점검할 내용

출력 형식은 학생용 활동지와 교사용 활용 안내로 나누어 줘.

평가 기준은 다음 성취기준을 반영해 줘.

출력 형식은 평가 요소, 도달 기준, 학생용 피드백 문장, 교사 관찰 포인트로 정리해 줘.

학생은 자신의 주장하는 글 초안을 바탕으로 주장, 근거, 출처, 글의 흐름, 문장 표현, 고쳐쓰기 방향을 점검해야 해.

3. 출처가 필요한 문장이나 자료가 있는지 점검하게 하기
4. 글 전체가 하나의 주제로 연결되는지 살펴보게 하기
5. 어색한 문장, 반복 표현, 띄어쓰기 등을 학생이 직접 찾게 하기
6. 다시 쓸 때 가장 먼저 고칠 부분을 학생이 선택하게 하기

학생이 답을 어려워하면 정답을 바로 알려 주지 말고, 예시 질문이나 선택지를 제공해 줘.

나는 학교에서 쉬는 시간을 지금보다 더 늘려야 한다고 생각한다.

첫째, 쉬는 시간이 많으면 학생들이 피로를 풀 수 있다. 우리는 하루 종일 수업을 받으면서 집중력을 사용한다. 뇌도 휴식이 필요하다. 쉬는 시간에 충분히 쉬면 다음 수업에 더 잘 집중할 수 있다.

둘째, 쉬는 시간이 많으면 친구들과 관계가 좋아진다. 운동장에서 함께 놀면서 우리는 서로를 더 잘 이해하게 된다. 좋은 관계는 학교생활을 더 즐겁게 만든다.

셋째, 충분한 휴식은 건강에 좋다. 움직이지 않고만 앉아있으면 몸이 경직된다. 쉬는 시간에 뛰어다니고 운동하면 우리 몸이 건강해진다.

따라서 학교에서 쉬는 시간을 더 늘려야 한다. 이렇게 하면 학생들이 더 행복하고 건강한 학교생활을 할 수 있을 것이다.
